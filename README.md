# E-Values Workshop Website

This is a static GitHub Pages-ready version of the NeurIPS 2026 workshop site.

## How to Publish

1. Push `index.html`, `assets/styles.css`, `.nojekyll`, and this README to the repository that backs `https://e-values-workshop.github.io/`.
2. In the repository settings, enable GitHub Pages from the branch that contains `index.html`.
3. GitHub Pages can serve HTML directly. Markdown is optional; it is only required if you want GitHub/Jekyll to convert Markdown into pages for you.

## Editing Content

Most visible text is in `index.html`. Replace the placeholder speaker names, affiliations, OpenReview link, and TBD dates as details become available.
